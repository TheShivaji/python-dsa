## 💡 Architecture & Philosophy

- 🚀 **1 Folder = 1 Master Notebook (`.ipynb`):** No cluttered loose files. Every day's practice is neatly packaged into a single runnable Jupyter Notebook with markdown explanations and interactive code blocks.
- 🧪 **Hands-on & Practical:** Every concept is cemented with real-world problems, edge cases, and algorithmic analysis.
- ⚡ **Modern Tooling:** Optimized for fast local execution with **`uv`** and **VS Code Jupyter**.

## 🚀 Quick Start: How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/TheShivaji/python-dsa.git
cd python-dsa
```

### 2. Launch with `uv` (Recommended)
Agar aapke paas **`uv`** installed hai:
```bash
uv run jupyter lab
# ya
uv run jupyter notebook
```

### 3. Or Open directly in VS Code
1. Open this folder in **VS Code**.
2. Install the recommended **Python** & **Jupyter** extensions.
3. Click on any `.ipynb` notebook and click **Run All** or press `Shift + Enter`!
